# 实战：一个真实项目的优化记录

这一册还没有正文。它会等到有一个具体的项目之后开始写，而不是先编一个假项目。

计划中的内容大致是这样：

- 项目背景与约束：模型是什么，硬件是什么，线上指标要求是什么。
- 基线：怎么测，测到什么，哪些数字可信，哪些只是估算。
- 分析：端到端时间怎么拆，瓶颈落在哪一层，为什么。
- 改造：图清理、融合、量化、引擎、批处理，每一步改了什么，收益多少，代价是什么。
- 上线：灰度、监控、回滚，以及上线之后才发现的问题。
- 复盘：哪些判断错了，哪些经验可以复用。

在拿到项目之前，这里只放目录和写作计划。正文、插图、PDF 都会在项目确定后补齐。
