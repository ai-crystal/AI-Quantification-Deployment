# 前言

部署做到一定深度，迟早会碰到一个问题：这个算子为什么慢。框架给的答案通常是“换一个更快的实现”，但换完之后可能只快了一点，也可能换出一个更慢的结果。要判断下一步往哪走，需要知道 GPU 的时间花在哪里，是算力、带宽，还是根本没把卡喂饱。

这一册讲的就是这层判断。它从一块 GPU 的构造讲起，经过 GEMM、卷积、归一化和注意力这些基本算子，最后落到 Nsight 和端到端延迟。书里会提到 CUDA，但不是一本 CUDA 编程教程；代码只用来解释结构，读懂就行。

读这一册之前，最好已经知道推理和训练的区别，知道算子、计算图、量化这些词大概指什么。第一章到第四章是硬件和性能模型，建议按顺序读；后面的算子章节可以挑着看，遇到不熟悉的再回头补。
